# PandaCode 0.2.40

- **iOS and Android simulators in the sidebar.** Open the phone tab in the right sidebar to see a live, 3D model of the device that you can turn and zoom.
  - Click the screen to tap, drag to swipe, scroll to scroll and type to enter text. Home, Lock, Back and Recents (Android) sit in a dock below, with dark mode and screenshot copy.
  - Devices look like the real products: iPhone 17 Pro in Cosmic Orange with its camera plateau, iPhone Air, iPhone 17, earlier iPhones, iPads, and Pixel phones and tablets, each with its official finishes.
  - Agents can use them too: they see the screen as an image or a list of elements, then tap, swipe, type, press buttons, install and launch apps and open links.
  - iOS uses Xcode's simulators; touch input needs AXe (`brew install cameroncooke/axe/axe`). Android uses the Android SDK emulator; if it is missing, "Set up Android emulator…" in the device menu installs it with Homebrew (about 2 GB).
- **Pull requests in the sidebar.** When an agent opens a pull request in a thread, it is linked automatically. The PR tab shows its state, checks, reviews, description, files with diffs and commits. "Link pull request…" in the branch menu attaches an existing one.
- **Token saver.** The Saver button in the composer turns on per-thread packs that help agents spend fewer tokens: Caveman (Lite, Full, Ultra), Lean code, Quiet tools and RTK compression. Turning on RTK installs it with Homebrew if needed. Hover a name to see what it does.
- **Colors that follow your wallpaper.** The accent color now comes from the current wallpaper. Choose Classic yellow, a swatch or any color in Settings → Colors.
- **VS Code themes.** Import a `.vsix` or install a theme from Open VSX by its ID, such as `dracula-theme.theme-dracula`. Only the theme's colors are read. While a theme is active, its colors stay put when the wallpaper changes.
- **Teams pick their own models.** Auto teams are led by the task's model, which chooses each worker's model from your installed ones or as your prompt asks.
- **Bot pages.** A setup checklist guides new bots, bots can be paused and resumed, and the header has Edit, Settings and a More menu with Reset and Delete.
- **A calmer layout.** Divider lines between panels are gone, the right sidebar's header blends in, the top-right icons are grouped, and notices are a slim line.
- **Cleaner threads.** Your messages are right-aligned bubbles without name rows. Copy and Fork appear when you hover a message and no longer take a line.

Known limitations: Android typing accepts plain ASCII text only. Android emulator setup was verified against Homebrew's package definitions, not yet on a fresh machine. Savings shown for Lean code and Quiet tools are estimates.

This is an Alpha preview. macOS uses ad-hoc signing without Apple notarization;
Windows does not yet have Authenticode signing. All platform updates retain
cryptographic signature verification. Linux requires X11/XWayland.
