# Swarm v0.2.0 — ULTRACODE V2 Multi-Agent Operating System, Windows PTT & Wallpaper Protocol Fixes

Swarm **v0.2.0** represents a major architectural upgrade, replacing static pipeline orchestration with **ULTRACODE V2** — a deterministic multi-agent operating system modeled on Anthropic's Claude Code Ultracode architecture and the 11-day Bun Zig-to-Rust migration methodology. This release also delivers 100% airtight fixes for Windows Voice Push-to-Talk (F8) and Windows local wallpaper asset protocol resolution.

---

## ⚡ What's New in Swarm v0.2.0

### 1. ULTRACODE V2 Deterministic Sandboxed Workflow Runtime (`ultra_runtime.rs`)
- **Deterministic Sandboxed Execution**: Workflows execute with strict sandbox isolation, keeping intermediate variables, loops, and raw tool outputs inside the runtime memory without polluting the main LLM conversation thread.
- **The Three Core Primitives**:
  - `await agent(prompt, opts?)`: Spawns an isolated sub-agent in a **100% virgin context** (`resume_id = None`) with options for role, owned files, worktree, model alias (`best`, `fast`, `1m`), and reasoning effort (`xhigh`).
  - `await parallel(thunks)`: Spatial concurrency engine (Fan-out) with synchronization barriers. **Fault-Tolerant Rule**: If an individual sub-agent suffers an error or timeout, `parallel()` catches the failure, logs telemetry, and yields `null` for that slot so the workflow can safely `.filter(Boolean)` and synthesize all surviving results.
  - `await pipeline(items, stages)`: Continuous streaming pipeline without global waiting barriers; downstream stages start processing finished items immediately while upstream stages process subsequent items.

### 2. Massive Concurrency Scaling & 1,000-Agent Circuit Breaker
- **Concurrency Scaling**: Default worker ceiling set to `std::cmp::min(16, cpus.max(4))`, configurable via `SWARM_WORKFLOW_MAX_CONCURRENT_AGENTS` from `1` up to **`256` concurrent agents**.
- **1,000-Agent Circuit Breaker**: Unbreakable atomic counter (`AtomicUsize`) enforces a hard ceiling of `1,000` total agent spawns per workflow run (`MAX_TOTAL_WORKFLOW_AGENTS = 1000`), cleanly stopping rogue loops.
- **Sub-Agent Destructive Command Firewall**: Intercepts and strictly blocks destructive global git operations (`git reset --hard`, `git stash`, `git clean`, `git checkout .`) from corrupting worktrees.

### 3. The Adversarial Review Triad (Zero Confirmation Bias)
- Replaces single-agent critic review with a deterministic 3-role triad:
  - **Role 1 — Implementer**: Generates code changes strictly within assigned boundaries; performs zero self-review.
  - **Role 2 — Twin Antagonistic Reviewers in `parallel()`**: Two independent reviewer agents spawned simultaneously in fresh virgin contexts with antagonistic prompts. Reviewer A focuses on Memory Safety, Concurrency, and Panics; Reviewer B focuses on Edge Cases, Math/Logic Precision, Security, and API Contracts.
  - **Role 3 — Surgical Fixer**: Receives deduplicated, consolidated defect reports and applies surgical remediation before verification runs.

### 4. Bun Port Industrial Methodology & Clustered Compiler Self-Healing
- **Phase 0 Ground-Truth Disk Artifacts**: Persists typological mappings and module ownership rules to `.swarm/ultra/ARCHITECTURE_MAP.md` and `.swarm/ultra/CONTRACTS.tsv`.
- **Clustered Parallel Compiler Self-Healing**: When global verification (`cargo check`, `npx tsc --noEmit`, etc.) fails, diagnostics are parsed into disjoint Per-Module Error Clusters and repaired simultaneously across a parallel swarm of fixer loops.

### 5. Built-in Specialized Ultracode Slash Workflows
- **`/deep-research <query>`**: 5-phase deterministic anti-hallucination pipeline: Clarify & Decompose -> Massive Parallel Fact Retrieval -> Atomic Claim Isolation -> **The Three-Vote Skeptic Check** (3 independent skeptical agents in parallel attempting to refute claims) -> Ground-Truth Report Synthesis with exact citations.
- **`/ultrareview`** (alias `/code-review ultra`): Parallel review swarm across modified files and callers with an adversarial false-positive filter and severity ranking (`Critical`, `High`, `Medium`, `Low`).
- **`/goal <objective>`**: Autonomous self-driving multi-turn loop with strict criteria evaluation.

### 6. Signature Activation UX: Glowing Purple `ultracode:` Keyword & `Ctrl+G` Inspector
- **Glowing Purple `ultracode:` Keyword Detection**: Typing `ultracode:` in the Composer input renders a vibrant glowing purple pill (`#a855f7`) and arms ULTRACODE V2.
- **Instant Keyboard Disarm (`Alt+W` / `Option+W`)**: Pressing `Alt+W` (or `Option+W` on macOS) immediately disarms the keyword trigger and reverts to plain text.
- **Human-Input Security Guard**: Only genuine interactive keyboard or voice input triggers keyword activation—preventing untrusted webhooks or background text injection from triggering massive workflows.
- **Pre-Flight Cost & Swarm Estimation Bar**: Interactive banner displaying estimated sub-agents, phases, and deep compute multiplier before heavy runs.
- **`Ctrl+G` Workflow Script & Live Swarm Matrix Modal**:
  - **Tab 1 (Generated Script)**: View the exact async JavaScript workflow (`agent()`, `parallel()`, `pipeline()`, `adversarialTriad()`) with syntax highlighting.
  - **Tab 2 (Live Swarm Matrix)**: Real-time visual grid of all active, queued, passed, null-filtered, and completed agent slots with live token usage and elapsed time.
- **Enterprise Safety Lock**: Disable workflows entirely via `"disableWorkflows": boolean` in Settings or `SWARM_DISABLE_WORKFLOWS=1`.

### 7. Windows Voice Push-to-Talk (F8) Key-Repeat Fix (100% Resolved)
- Guarded `isVoiceActive`, `isStarting`, and `isManualClick` states to eliminate OS key-repeat re-triggering.
- Graceful `getUserMedia` async resolution: rapid key release cancels recording immediately and terminates media tracks without leaking open mic streams.
- Chromium/WebView2 `SpeechRecognition` transient errors (`network`, `no-speech`) now log warnings rather than abruptly shutting down audio capture.
- Added `window.blur` listener to automatically release PTT on loss of window focus or Alt-Tab.

### 8. Windows Wallpaper Path Normalization & Asset Protocol Fix
- Windows drive letter paths (`C:\...`, `/C:/...`, `file:///C:/...`) and backslashes are normalized to forward slashes before URL resolution, preventing CSS escape corruption (`\U`).
- Added Windows drive letter globs (`"*:**"`, `"C:**"`, `"C:/**"`, `"D:**"`, `"D:/**"`) to Tauri asset protocol scope.
- `honeycombs.svg` and bundled scenes reliably resolve across WebView2, WebKit, and local file storage.
