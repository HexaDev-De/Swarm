# A new panda icon and sturdier agent teams

## Agent teams

- **Teams no longer stall.** Claude architects can no longer wait on background commands, monitors or scheduled wakeups. These never report back after the turn ends. If an architect still ends a turn without handing out work or finishing, PandaCode asks it once to continue before pausing.
- **A stuck turn is stopped after 20 minutes without output.** A silent worker fails and goes to the architect. A silent architect turn shows a notice, and its workers keep running. Turns waiting on your approval or answer never count as silent.
- **Failed workers are handled right away.** When a worker fails while others are still running, the architect gets it at once and can retry or replace it.
- **Faster and cheaper turns:**
  - Team tools no longer ask for approval.
  - Reviews start warm.
  - Each conversation gets the team rules once. Later turns get a one-line reminder and only new messages.
- **Fixes:**
  - Asking the team a question no longer starts work you didn't ask for.
  - A reused task name runs again for a new request.
  - The assignment limit counts only the current request.
  - One team's missing folder, or one worker that can't start, no longer stops the rest.
  - Pause, Stop and restarts don't use up a worker's tries.
  - Resume works right after Pause and at the round limit (four more rounds, up to 20).
  - A failed retry no longer shows the previous attempt's result.
- **You see more:**
  - A spinning ring marks each working worker line.
  - "Needs input" appears on the Architect & workers button when a worker waits on you, even with the panel closed.
  - Pauses and failures you didn't ask for appear as a notice.

## Questions

- **Questions from Codex render rich Markdown:** links, project images, charts, SVG drawings and static HTML views. Remote images stay links, and no script runs.
