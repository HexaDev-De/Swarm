# PandaCode 0.2.26

- Each thread now keeps its own right sidebar state while PandaCode is open: the selected tab, folder or file, browser URL, and whether the sidebar is open. Switching threads restores that thread's panel; new threads start with it closed.
- Get notified when an installed coding agent has an update. Choose Update from the popup, or check in Settings → Agents. Supported installations use their official updater, show progress, and verify the resulting version. Other installations show manual guidance.
- Agent update checks are cached and updates start only when requested, after running work is stopped. Shared Claude installations used by GLM and MiMo are checked together.
- Delete a thread and its worker history from the task menu, with confirmation. Project files and worktrees are preserved, and running tasks cannot be deleted.
- Fixed browser and file-preview races when switching threads quickly, including keeping an in-flight screenshot attached to its original thread.

Browser pages reopen at their saved URL when switching threads. Agent update availability depends on the installed harness and installation method.
