# The prompt box, properly fixed

## Fixes

- **No scroll bar in an empty prompt box, for real this time.** On the latest macOS the empty prompt box still showed a sideways scroll bar after 0.3.13, which only fixed the vertical one. The prompt box never scrolls sideways now; long words and links wrap instead, and long messages still scroll up and down.

## Known limitations

- Six browser tests that already failed before this release still fail; they are unrelated to this change.
