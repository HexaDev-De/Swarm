# PandaCode 0.2.35

- Import conversations from Claude Code and Codex. Open Import conversations from the sidebar or Go to anything, search your conversations, check the ones you want, and import them.
  - Each one becomes a task in the project for its folder. The project is added if needed.
  - Its history keeps its original times, and your next prompt continues the same session.
  - Conversations already in PandaCode link straight to their task.
- New task opens immediately, but the task is only saved once you send its first prompt. Leaving an untouched new task discards it. One with typed text, attachments or a worktree is kept, and New task brings it back.
- When a single project is selected, its tasks are listed without a repeated folder heading, and up to 20 show before "Show more". "More in other projects" is now a single line at the bottom of the sidebar.

Known limitations: only readable text is imported, and tool calls appear by name. Conversations whose folder no longer exists on this computer cannot be imported.

This is an Alpha preview. macOS uses ad-hoc signing without Apple notarization;
Windows does not yet have Authenticode signing. All platform updates retain
cryptographic signature verification. Linux requires X11/XWayland.
