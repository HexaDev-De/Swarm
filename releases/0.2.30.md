# PandaCode 0.2.30

- The Codex usage panel (`/usage`) now shows daily token use as an activity calendar instead of a collapsed list. Each column is a week, and darker squares mean heavier days. The header totals tokens and active days for the period.
- Hover or click a day to see its exact token count. With the keyboard, the calendar is a single stop: arrow keys move by day and week, and Home and End jump to the ends. `/usage daily` opens with the calendar focused.
- The calendar fits the panel and scrolls on narrow windows, keeping the newest weeks in view.

Known limitations: the calendar appears only for Codex accounts that report daily usage. The Account limits view for other agents is unchanged.
