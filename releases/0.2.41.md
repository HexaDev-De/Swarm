# PandaCode 0.2.41

- **Your messages sit on the right.** Message bubbles now line up with the right edge of the conversation instead of floating near the middle on wide windows, and their text reads left to right inside the bubble.
- **Tidier activity rows.** "Worked for…", tool activity and changed-file rows start at the same edge as replies, without the old indent.

This is an Alpha preview. macOS uses ad-hoc signing without Apple notarization;
Windows does not yet have Authenticode signing. All platform updates retain
cryptographic signature verification. Linux requires X11/XWayland.
