# PandaCode is open source

PandaCode is now free and open source under the PandaCode License: the MIT
License, plus a requirement that forks used commercially or released publicly
say "This is a fork of PandaCode" and link back. The code lives at
[github.com/aicodeking/pandacode](https://github.com/aicodeking/pandacode).

- **No license key, no account.** Every feature works as soon as you install. There is nothing to activate or renew.
- **No telemetry.** PandaCode does not phone home. Your projects and conversations stay on your machine and go only to the coding agents and services you choose. The only automatic requests are anonymous checks for new versions of your installed coding CLIs and a daily public model price list.
- **Updates on GitHub.** New versions are published as [GitHub Releases](https://github.com/aicodeking/pandacode/releases) for macOS (Apple silicon), Windows x64 and Linux x64. Download the new build and install it over the old one; your tasks and settings are kept.
- **Build it yourself.** Clone the repository, run `npm ci` and `npm run tauri dev`. CONTRIBUTING.md lists the prerequisites, tests and pull request process.
- **Contribute.** Bug reports and ideas are welcome as GitHub issues, and security problems can be reported privately through GitHub Security Advisories.

Known limitations: release builds are not code-signed yet, so macOS asks you to choose Open Anyway in Privacy & Security the first time, and Windows SmartScreen may warn about an unknown publisher. The in-app update installer is gone; check the Releases page for new versions.
