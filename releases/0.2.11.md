PandaCode 0.2.11 adds optional Jev assistance for agents and teams.

- Set up Jev in Settings → Agents → Jev · Optional add-on. Decision assistance and browser testing are separate switches, both off by default. PandaCode continues to work without a Jev key.
- Use Jev to suggest a configured worker, find relevant recent conversation excerpts, review saved work, and check changed files against project rules. Preview the evidence first and keep reports locally. Suggestions do not automatically change models, assign work, or approve completion.
- Let agents test local app previews with Jev in a separate browser session. Follow live actions, inspect screenshots, and read independent final checks. Browser testing uses a separately installed runtime and your own TypeSafe and text-model credentials; provider usage is billed separately.
- Mention project files with @ in the prompt. Copy messages and responses, or fork a conversation from a selected saved message, including from the board and quick overlay.
- Includes desktop compatibility and process-management improvements. This release is for Apple silicon Macs; other platform downloads are not being published in this update.

Jev is a preview integration. Model judgments are advisory, and browser checks verify only the supplied assertions. Your existing coding providers, approvals, conversation history, and normal browser workflow remain available.
