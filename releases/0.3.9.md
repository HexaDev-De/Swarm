# The conversation stays put when you send

## Conversation

- **No more jump when you send.** The conversation stays at the bottom while your message and the reply stream in, through tool rows and formatting. Scroll up to read and it leaves you there; scroll back to the bottom and it follows again.

## Queued messages

- **Send now.** Every queued message has a Send now button. If the agent is idle or the queue is paused, it goes out right away. If an agent is running, PandaCode stops that run and sends this message first; the rest of the queue keeps its order.
- **Steer is easier to find.** While a Claude or Codex agent is running, a labelled Steer button sends the queued message into the running reply.

## Known limitations

- Send now is not offered in bot conversations, which send their queue on their own.
- Eight browser tests that already failed in 0.3.8 still fail; they are unrelated to these changes.
