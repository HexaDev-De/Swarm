# A smoother workspace, connected to GitHub

- A consistent warm glass material and spring motion across menus, dialogs, panels, board cards, toasts, and segmented controls, with reduced-motion and contrast fallbacks.
- A project, checkout, and branch bar above every task's prompt. Move an unstarted task into a worktree while keeping its draft, or create a sibling worktree task from an existing conversation.
- Choose a starting branch, reuse an existing branch, recover a missing worktree, and clean up finished checkouts with checks for uncommitted work and unmerged branches.
- Optional GitHub integration through your signed-in GitHub CLI. Import issues as pending board tasks and push a branch to open a linked pull request.
- Linked issue and pull-request status appears on tasks and the board. Turn GitHub integration off in Settings to hide its controls and stop its CLI requests.

Known limitation: GitHub mention searches and issue-context resolution can fail because the issue lookup requests a pull-request-only CLI field. Board issue imports and pull-request creation use separate commands.
