# PandaCode 0.2.36

- **Bots: always-on assistants on your own computer.** Open Bots from the sidebar or Go to anything and start from a template or from scratch. Give a bot a job, instructions and standing goals, and choose its harness, model and permissions.
  - Chat with it right in the Bots window, with streamed replies and inline approvals. Each conversation is also an ordinary task you can open in the workspace.
  - It remembers what matters, and you can see, add and remove its memories. It can schedule work for itself (once, every few minutes or hours, daily or on weekdays). Optional check-ins review its goals and message you only when something needs you.
  - Reach it from a private web chat page, Telegram, Slack, Discord or WhatsApp. Each channel has a guided setup with step-by-step links and copy buttons, a one-click Slack app, a Discord invite link, and a credential check before anything is saved. New senders pair with a four-digit code you approve.
  - In any chat, /stop stops its work, /new starts over, and replying yes, no or always answers an approval. Rules can allow or deny kinds of actions; risky ones such as sudo, force pushes and deleting files always ask.
  - Pause, reset or delete a bot at any time. The Activity tab records everything it did.
- **Queue and steer while an agent works.** The prompt stays open during a run: Enter queues your message to send when the run finishes, and Command-Enter steers the running turn (Claude-family harnesses and Codex). Queued messages can be edited, reordered and removed.
- **Usage limits.** When Claude Code or Codex hits a usage limit, the task shows when it resets. Continue now, or let it resume automatically at reset.
- Agents can search tasks, queue and steer messages for other tasks, request a stop, and pin tasks in the same project.

Known limitations: bots run while PandaCode is running. WhatsApp needs a public HTTPS address for Meta's webhook, such as a Cloudflare or Tailscale tunnel, and only allows free-form replies within 24 hours of the person's last message. Chat channels carry text only. On macOS, after an update you may be asked to allow PandaCode to read saved channel tokens from Keychain.

This is an Alpha preview. macOS uses ad-hoc signing without Apple notarization;
Windows does not yet have Authenticode signing. All platform updates retain
cryptographic signature verification. Linux requires X11/XWayland.
