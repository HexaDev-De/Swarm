# PandaCode 0.2.27

- Pin threads above Active and Inactive, and drag threads into your preferred order within each section. Pins and ordering are saved across restarts. Right-click a thread for Pin, Unpin, Move up, and Move down; focused threads also support Option/Alt + Up/Down.
- Terminals now belong to their thread, with multiple tabs that retain their processes and output when switching threads. Minimize a terminal without stopping it; closing a terminal with running commands offers Minimize instead.
- New terminals automatically import supported font, cursor, spacing, and color settings from local Ghostty, Kitty, Alacritty, WezTerm, or Windows Terminal configuration. The most recently modified supported configuration is used; configuration code is never executed.
- Earlier messages load as you scroll up, preserving your reading position while responses continue streaming. This also works in worker conversations and the quick overlay.
- Fixed browser pages going blank after switching threads. Restoring a page and pressing Reload now explicitly restore its visibility.
- Fixed terminal startup output being lost when another tab is busy, and restarting an exited harness console for a new command.

Terminal processes and open tabs are retained while PandaCode is running. Appearance import supports static settings; dynamic configuration and named external themes keep PandaCode's defaults.
