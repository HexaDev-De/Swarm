# PandaCode 0.2.39

- **Richer Markdown everywhere.** Agent replies, streamed text, subagents, team workers, the quick launcher and bot chats now render through Software Mansion's Enriched Markdown engine.
  - Task lists show real checkboxes.
  - GitHub-style notes and warnings (`> [!NOTE]`, `> [!WARNING]`) appear as colored callouts.
  - Tables keep their column alignment, and numbered lists keep their starting number.
  - LaTeX math, inline `$…$` and display `$$…$$`, is typeset. Prices like "$5" stay plain text.
  - HTML written inside a reply is shown as text, never run.
- **A page for each bot.** Click a bot in the sidebar to chat with it on its own page, with streamed replies, suggestions and inline approvals. Its memory, schedules, channels, rules and activity sit in a panel beside the chat, and the pencil edits its name, instructions and model. The panel can be hidden, and the app remembers your choice.
- The bots' web chat page uses the same Markdown engine.

Known limitations: optional link titles (`[text](url "title")`) are not shown. Math in the bots' web chat page is shown as code.

This is an Alpha preview. macOS uses ad-hoc signing without Apple notarization;
Windows does not yet have Authenticode signing. All platform updates retain
cryptographic signature verification. Linux requires X11/XWayland.
