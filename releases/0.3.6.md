# Safer cloud deploys and no more lost queued messages

## Queue

- **Queued messages are never lost.** If a queued message can't be sent (an attachment can't be read, or the task restarted), it goes back to the front of the queue and the queue waits.
- **Bot conversations keep queued attachments.** Images, documents and folders attached to a queued bot message now reach the agent. A failed send puts the message back instead of dropping it.

## Cloud and deploys

- **The cloud CLI always asks first.** `pandacode_cloud_cli` asks for approval on every call, even in full-access mode, because it can create or delete paid resources.
- **AWS credentials stay out of the agent's reach.** `aws configure`, the `sts` commands that hand out credentials, and `--debug` are refused. Access key IDs, secret keys and session tokens are redacted from AWS CLI output.
- **Cloudflare deploys no longer hang.** Large Wrangler output used to stall a deploy until its 30-minute timeout. A timeout now also stops Wrangler's child processes.

## Local VMs

- **Linux desktops finish installing.** The idle watcher no longer stops a Linux VM while its desktop installs.
