# DeepSeek, a document reader and generative UI

## Harnesses

- **DeepSeek is a new harness.** If you use the [DeepSeek Harness](https://platform.deepseek.com/api_keys) (`npm i -g @deepseek-ai/dsh`), pick it in the model picker like any other harness. PandaCode launches `dsh --profile acp`, lists the models dsh offers and its reasoning efforts (Off, Low, High, Max).
- **Your key, only where it is needed.** An API key is optional: save one in Settings → Providers (it stays in the system keychain), set `DEEPSEEK_API_KEY`, or let dsh use its own stored credentials. A saved key is handed only to the dsh process.
- **Permissions through dsh's sandbox.** Standard and Accept edits write in the workspace and ask before going further, Plan mode is read-only, Full access never asks. Details are in [docs/approvals.md](../docs/approvals.md).
- **Teams can switch models.** A task with a team can change its model and reasoning effort from the composer's model picker; you no longer get "Use the team controls to switch the architect".

## Reading and writing

- **A reader in the right sidebar.** Markdown and text files open as a rendered page with a Rendered / Raw toggle, selectable text, Copy file, a wrap toggle, word count and reading time. Files from the Files tab, file links in messages, and files an agent opens all land here. Agents are asked to open essays, notes and docs here after writing them.
- **Code files read better too.** Line numbers stay put but are not copied with the code, and long lines can wrap.

## Generative UI in threads

- **Agents can answer with interface, not just text.** A reply can include tables you can sort, charts (bar, line, pie, area, sparkline), stat tiles, cards, callouts, tabs, accordions, steps, timelines, checklists, plans, file trees, diffs, code with a filename, terminal output, pros and cons, image galleries, forms, buttons and follow-up suggestions, arranged in stacks and grids.
- **Agents can build their own views, safely.** Custom views are static HTML and CSS drawn in the thread: no scripts, frames or remote content, with a few built-in behaviours (toggle, tabs, show a value, insert a prompt). Pages that need scripts are opened in PandaCode's browser instead.
- **Nothing runs without you.** Buttons, chips and forms only put a prompt in the composer for you to read and send.
- **Code blocks have a Copy button**, and collapsible sections and follow-up chips render in replies.

## Fixes

- Typing after an `@` mention of a file whose name has spaces no longer reopens the file picker on every space (macOS smart quotes curled the mention's quotes).
- Clicking into a conversation no longer draws a blue focus outline around it.

## Known limitations

- Mermaid diagrams show as labelled source, not drawings.
- An agent's ```html or ```svg code example now renders as a view; its source is one click away under "Source".
- DeepSeek usage limits are not shown in PandaCode; check the DeepSeek platform.
- PandaCode's DeepSeek tests replay recorded dsh sessions; live runs depend on your dsh setup.
- Six browser tests that already failed before this release still fail; they are unrelated to these changes.
