# Swarm v0.1.2: ACP Protocol Fixes, Windows PTT & Strict Artifact Standardization

**Swarm v0.1.2** delivers critical runtime reliability improvements for the Antigravity ACP provider, resolves Windows push-to-talk microphone hardware termination on key-repeat, fixes Windows wallpaper file loading and URI normalization, repairs updater manifest Base64 signature encoding, and enforces strict, deduplicated release artifact distribution.

---

## 🛠️ Key Fixes & Improvements in v0.1.2

### 1. Fix Antigravity ACP Phase 0 Stuck State & 90s Execution Timeout
- **Problem**: When using the Antigravity ACP provider or long-running subagents, `protocol.phase` remained at `0` because it was not transitioning during live ACP handshakes. As a result, the startup grace deadline aborted complex agent runs after 90 seconds even while tools (`write_file`, `run_command`) were actively executing.
- **Resolution**:
  - Configured live phase transitions (`phase = 1`) in `src-tauri/src/providers/acp.rs` upon ACP session ID registration (`id == 2`), initial prompt dispatch (`kimi_prompt`), and reception of streaming chunks or tool events.
  - Increased Antigravity's initial startup grace window from 90s to 180s in `src-tauri/src/providers.rs` (`initial_timeout = 180`).
  - Safeguarded the select-loop timeout arm: provider runs are never prematurely timed out if background jobs or queued tool executions are actively in flight (`!jobs.is_empty() || !queued.is_empty()`).
  - Marked `protocol.phase = 1` immediately whenever any message frame is received from the child process.

### 2. Fix Voice Mode Push-to-Talk Auto-Close on Windows (F8 Key-Repeat)
- **Problem**: Holding `F8` on Windows fires rapid OS auto-repeat `keydown` events every ~30ms. Unhandled repeats invoked `start()` multiple times, spawning conflicting audio capture contexts and triggering Windows to shut down the microphone hardware.
- **Resolution**:
  - Injected an active state flag (`isVoiceActive`) and guarded against `e.repeat` in `src/voice-vibe.ts`.
  - Holding `F8` now maintains a single stable audio stream.
  - On `keyup`, audio tracks are cleanly halted via `track.stop()`, releasing the Windows audio device reliably.

### 3. Fix Wallpaper Rendering on Windows (Backslash Escapes & Asset Protocol)
- **Problem**: Windows file paths use backslashes (`\`), which caused CSS `url()` parsing errors (e.g., `\U` parsed as an invalid Unicode escape). Furthermore, WebView2 blocks raw `file:///` URLs due to strict local CORS restrictions.
- **Resolution**:
  - Normalized Windows backslashes to forward slashes in `src/wallpapers.ts`.
  - Wired Tauri's `convertFileSrc` to safely resolve local wallpaper files to WebView2-compliant asset URLs (`http://asset.localhost/...`).
  - Retained clean passthroughs for remote URLs, data URIs, and bundled web assets (such as `/honeycombs.svg`).

### 4. Auto-Updater Manifest Signature Encoding (`latest.json`)
- **Problem**: In previous release packaging, raw plaintext strings were written to `.sig` files and injected into `latest.json`, which caused the Tauri v2 updater to fail with Base64 decoding errors (`invalid encoding in missing Data`).
- **Resolution**:
  - Implemented `sanitizeSignature(rawSig)` in `scripts/release/generate-latest-manifest.mjs` to extract valid Base64 signature lines from Minisign files.
  - Omitted the `"signature"` property entirely when no valid cryptographic signature is present, ensuring compliance with the Tauri v2 update manifest schema.

### 5. Strict Artifact Deduplication & Standardization
- **Problem**: Previous releases bundled both default Tauri build names (e.g. `Swarm_0.1.1_x64-setup.exe`, `Swarm_0.1.1_amd64.deb`, `Swarm_0.1.1_amd64.AppImage`) and standardized names, causing confusion.
- **Resolution**:
  - Configured CI (`.github/workflows/release.yml`) so `tauri-action` acts purely as a build engine without uploading raw build bundles.
  - Standardized the artifact suite to exactly 5 clean, stable assets (and their corresponding `.sha256` and `.sig` sidecars):
    - `Swarm-Linux-x86_64.AppImage` (repacked without host-bundled `libwayland-*.so*`)
    - `Swarm-Windows-x64-setup.exe`
    - `Swarm-macOS-arm64.dmg`
    - `Swarm-macOS-arm64.app.tar.gz`
    - `latest.json`
  - Automated deletion/pruning of any non-standard assets in the release publish job.
