# Pi joins PandaCode

## Harnesses

- **Pi is a new harness.** If you use the [Pi coding agent](https://github.com/earendil-works/pi), pick it in the model picker like any other harness. PandaCode uses the accounts, models and extensions you set up in Pi, lists its models by provider, and offers Pi's thinking levels. Install it with `npm i -g @earendil-works/pi-coding-agent` and sign in from its CLI first; Settings → Providers can point to a different Pi executable. Thanks to @ExcuseMeBro for the integration.
- **Everything you expect from a task.** Pi replies stream in with their tool activity and context usage, accept screenshots, and resume the same Pi session on your next message. Pi works in tasks, teams and bots.
- **Steer a running reply.** While Pi is working, ⌘/Ctrl Enter sends your message into the current reply through Pi's own steering.
- **Pi's slash commands.** Commands, skills and prompt templates from Pi and your project show up in the composer's slash menu.
- **Permissions you choose.** Standard asks before edits, commands and other tools that change things; Accept edits allows file edits; Plan mode allows only reading; Full access runs everything. PandaCode enforces these through a small Pi extension, and its app tools reach Pi through the same authenticated local connection other harnesses use.
- **Pi keeps going when it should.** A reply that Pi retries after a temporary error, or continues after compacting its context, is not cut off; you see "Retrying" and "Compacting context" while it happens.

## Known limitations

- Pi's interactive console needs Full access; use the task chat for the other permission modes.
- Pi extensions that ask you to pick from a list, type text or edit something are declined for now. Yes/no confirmations work.
- Pi does not report subscription usage, so its usage card says so.
- Pi runs were tested without paid model calls.
- Eight browser tests that already failed in 0.3.8 still fail; they are unrelated to these changes.
