# iPhone Duo, GitHub Actions and Railway deploys

## Harnesses

- **OpenCode lists its models right away.** With nothing chosen in Settings → Agents → OpenCode, the picker shows the whole catalog; choosing models there still narrows it. Newer OpenCode CLIs that reject `models --verbose` fall back to the plain list. (#31)
- **pnpm installs on Windows.** OpenCode and Pi installed with pnpm now launch: PandaCode follows the `.cmd` shim only to the entry its package declares, and never through a shell. Thanks to @Crqptx. (#30)

## Simulators

- **iPhone Duo.** With Xcode 27.1 or later, add an iPhone Duo from the Simulators tab. The panel draws its cover and inner displays, switches between Closed, Book and Open, and agents can fold it, tap and type on either display.
- **Android emulators on Windows.** The Simulators tab now appears on Windows and lists Android emulators from an installed Android SDK. AVDs load when `HOME` is unset, the emulator starts without a console window, and newer system images such as `android-37.0` show their API level. One-click SDK setup on Windows is not part of this release. (#20)

## GitHub view

- **CI at a glance.** Pull requests show a Passed, Failed or Pending checks badge.
- **Actions tab.** Each repository lists its recent workflow runs with status, branch and age. A failed run has a Fix button that starts a task, which reads the failure with `gh run view --log-failed`. (#33)

## Deploys

- **Railway.** Connect an account or workspace token in Settings → Agents → Cloud sandboxes. PandaCode uses an installed `railway` or a pinned `npx @railway/cli@5.71.0`; the token reaches only the CLI's environment and is scrubbed from output. Only deploy-related commands run. Thanks to @RimasTam. (#22, #25)
- **Google Cloud.** Uses your installed `gcloud` and its login with a project and region you set. Commands that print or create credentials are refused, tokens are scrubbed from output, and usage reporting is off. (#22)

## Sidebar

- **Completed tasks leave the sidebar.** Moving a task to Completed hides it from the sidebar, pinned or not; it stays on the board and comes back when reopened. Thanks to @ExcuseMeBro. (#32)

## Fixes

- **macOS window dragging.** The whole empty header drags the window again, including the project name and the space between toolbar buttons. (#21)
- **Blank window on Linux.** The AppImage no longer bundles old Wayland libraries that stopped Mesa 25+ from starting WebKit. Thanks to @zupat. (#1, #24)
- **Releases from forks** link their own updater files, and versioning works on CRLF checkouts. Thanks to @RimasTam. (#27)
- A repository hook test no longer depends on your global `core.hooksPath`. Thanks to @webdevtodayjason. (#23)

## Known limitations

- iPhone Duo needs Xcode 27.1 or later on macOS.
- Android on Windows was not tested on a Windows machine for this release.
- The Linux AppImage repack is new; please report if the window is still blank.
- GitHub Actions status updates when the GitHub view refreshes; there are no push notifications.
- Six browser tests that already failed in 0.3.14 still fail; they are unrelated to these changes.
