# PandaCode 0.2.43

- **Agent teams.** In Settings → Agents → Agent teams, create a named team: choose the models it may use and which one leads. Your teams appear at the top of the model picker. Pick one and the lead plans the work and runs workers using only that team's models; PandaCode refuses any other model it asks for. Picking an ordinary model switches the task back to a single agent.
- **Classic team setup.** Prefer choosing every worker yourself? Turn on Settings → Agents → Classic team setup and the Team button opens Architect & workers again, with team profiles, per-worker models and run limits.

This is an Alpha preview. macOS uses ad-hoc signing without Apple notarization;
Windows does not yet have Authenticode signing. All platform updates retain
cryptographic signature verification. Linux requires X11/XWayland.
