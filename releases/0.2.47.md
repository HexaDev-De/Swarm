# PandaCode 0.2.47

- **VM screens show up.** The VM and cloud machine screens now appear in the VM panel in the desktop app. Frames were being blocked by the app's security policy; they are now drawn directly.
- **Linux VMs come with a desktop.** Creating a VM now starts it straight away, and any Linux VM without a desktop gets a light Xfce desktop with automatic login installed in the background the first time PandaCode starts it (a few minutes). The panel shows the console and the progress meanwhile, and agents can run commands right away. "Add a desktop" only appears if that install fails, to try again.
- Clicks on the VM screen land precisely in the native app's WebKit view, including when the panel is narrow.

This is an Alpha preview. macOS uses ad-hoc signing without Apple notarization;
Windows does not yet have Authenticode signing. All platform updates retain
cryptographic signature verification. Linux requires X11/XWayland.
