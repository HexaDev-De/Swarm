# PandaCode 0.2.48

- **Bot pages, redesigned.** A bot's page now reads like a task: the same column width and text size, replies as plain formatted text, and your messages in the familiar bubble.
- **A proper message box.** Bots use the full task composer, with chips for the bot's model, permissions and check-ins that open the matching setting.
- **Better settings panel.** Bot settings sit in a full-height side panel with a section header for each tab, app-sized fields, tidy lists, clear empty states and a close button.

This is an Alpha preview. macOS uses ad-hoc signing without Apple notarization;
Windows does not yet have Authenticode signing. All platform updates retain
cryptographic signature verification. Linux requires X11/XWayland.
