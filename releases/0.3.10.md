# A quieter changed-files card

## Conversation

- **The change-tracking note moved behind an ⓘ.** When PandaCode could not capture every edit in a turn, the changed-files card used to add a paragraph under the file list. That note is now an ⓘ beside "N changed files" and the +/− counts; hover it to read the details.
