# PandaCode 0.2.16

- New tasks start with Full access across supported coding harnesses, using each harness's native permission policy.
- Keep saved task permissions when switching harnesses or using a team profile. Workers and forks keep their parent task's permission choice.
- Install the macOS app with a disk image: open the download and drag PandaCode into Applications.
- Existing installations continue receiving cryptographically verified updates.

This is an Apple silicon Alpha preview. macOS uses ad-hoc signing while Apple Developer enrollment is pending; it is not Apple notarized.
