# PandaCode 0.2.24

- Switch harnesses in an idle task while keeping the conversation and project. A concise handoff explains what carries over, and earlier replies keep their original provider labels.
- Open HTML, SVG, images, and other previewable project files in the built-in browser. File references in agent responses can link directly to a preview or source view.
- Use local and cached slash commands immediately while provider commands load in the background, with clearer loading feedback and retry.
- Improve Windows Codex npm-launcher and Antigravity path compatibility.
- Give Antigravity more time to discover models on a cold start, share successful metadata, and reliably refresh stale model lists.
- Check Antigravity's connection separately from its installation status, and see clearer startup progress and useful provider failure details.
- See Claude's authentication source in Settings and optionally prefer its saved login over inherited environment credentials.
- Reduce snapshot-related startup delays and remove misleading change warnings after replies that did not produce a usable file diff.

Alpha preview. Windows launch behavior and the reported Antigravity cold-start latency still require verification on affected machines. Conversation transfers include bounded text history; private reasoning, tool execution state, and earlier image bytes do not transfer between harnesses.
