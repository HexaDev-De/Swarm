# PandaCode 0.2.34

- A more compact sidebar. New task and Search are simple rows with their shortcuts, and the project filter sits in the "All projects" label above your tasks.
- Tasks are grouped into one folder per project, with the most recently active project first. Each task is a single line showing its agent, title, status and age.
- Folders show six tasks with a "Show more" link, and remember when you collapse them. Opening a task from a collapsed folder opens it.
- Pinned tasks stay at the top and show their project. Tasks without activity in the last 24 hours are dimmed instead of moving to a separate Inactive group.
- Drag or use Alt+Arrow keys to reorder tasks within a project.

This is an Alpha preview. macOS uses ad-hoc signing without Apple notarization;
Windows does not yet have Authenticode signing. All platform updates retain
cryptographic signature verification. Linux requires X11/XWayland.
