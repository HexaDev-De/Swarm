# Automatic updates and a GitHub view

- **PandaCode updates itself.** It checks GitHub Releases at launch and every six hours, downloads a new version in the background and verifies its signature. It restarts to install once no agent is working and you've stepped away, or right away from **Restart to update** in the status bar. Settings → About shows the status, offers Check now, and can turn automatic updates off.
- **GitHub view.** A third view beside Conversation and Board lists your repositories. For each one: its threads, open pull requests and open issues. Review a pull request, fix its checks, address review comments or merge it when ready; solve an issue in one click or open it in a thread. Every thread is linked to its pull request or issue, and repositories that are only on GitHub can be cloned from there.

**Updating from 0.3.0:** install this version once from the Releases page. From then on, PandaCode updates itself.
