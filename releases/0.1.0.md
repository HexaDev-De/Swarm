# Swarm v0.1.0: Multi-Agent AI Coding Workspace

Welcome to the flagship launch of **Swarm (v0.1.0)** — an open-source, blistering-fast, native desktop workspace for local and cloud coding agents. Built on the architectural foundation of **PandaCode v0.3.16** under the [Swarm License](LICENSE), Swarm fuses native Rust and Tauri 2 system performance with autonomous multi-agent swarm orchestration, side-by-side LLM racing, and visual design canvas tooling.

Swarm requires **no accounts**, **no subscriptions**, **no license checks**, and **zero telemetry**. Your code, conversations, git branches, and credentials remain entirely local on your machine.

---

## 🚀 Why Swarm Stands Out: Deep-Dive Feature Breakdown

### 1. ULTRACODE Multi-Agent Engine
Complex engineering tasks overwhelm traditional single-agent chat interfaces. Swarm's **ULTRACODE Engine** (`src-tauri/src/ultra_engine.rs`, `src/ultracode.ts`) introduces an autonomous hierarchical multi-agent pipeline:
- **Architect Reconnaissance Turn**: Dynamically analyzes the user's objective and codebase, automatically choosing between `solo_deep` (targeted single-task refactor) and `parallel_swarm` (distributed multi-module execution).
- **Locked Semantic Interface Contracts**: Before spawning worker agents, the architect defines and locks shared schemas, TypeScript interfaces, and Rust traits as read-only ground truth.
- **Isolated Git Worktree Concurrency**: Up to 8 parallel worker agents operate concurrently in dedicated temporary worktrees (`.git/ultra_worktrees/`), eliminating git lock contention and dirty file collisions.
- **Local & Global Verification Gates**: Each subtask executes localized lints (`tsc`, unit tests) before triggering the global test suite and automated conflict-free git merge back into the main branch.
- **Critic Escalation & Automated Self-Healing**: Failed tests trigger a dedicated critic review turn with auto-generated escalation patches.

### 2. Dual-Harness Arena (2x Race Mode)
Developers no longer have to guess which model or coding CLI performs best for a given problem. The **Dual-Harness Arena** (`src-tauri/src/arena.rs`, `src/arena.ts`, `src/arena.css`) allows developers to race two AI harnesses head-to-head on the identical prompt in isolated worktrees:
- **Real-Time Telemetry**: Live side-by-side comparison of Time-To-First-Token (TTFT), tokens-per-second throughput, elapsed wall time, and total token expenditure.
- **Unified Diff & Visual Voting**: Inspect split code diffs and visual webview outputs simultaneously, with one-click branch adoption to merge the winning solution into `main`.

### 3. Interactive 3-Column Design Canvas
Bridge the gap between product design and production code with Swarm's Figma-style visual design workspace (`src-tauri/src/design_canvas.rs`, `src/design-canvas.ts`, `src/design-canvas.css`, stored in `.swarm/design/`):
- **DOM Layers Tree**: Complete interactive visual tree reflecting component hierarchy with drag-and-drop layer reordering.
- **Multi-Device Infinite Viewport**: Pan and zoom fluidly across simultaneous device viewports, including Desktop (1440×900), iPhone 16 Pro (393×852), iPad Air, and responsive custom viewports.
- **Live CSS Properties Inspector**: Real-time adjustment of layout (flex/grid), typography, spacing, borders, shadows, and colors with immediate visual feedback.
- **AI REMIX Prompt Bar**: Select any visual element or artboard and instruct the AI to restyle, redesign, or add responsive states with context-aware prompt injection.
- **One-Click Build / Convert Artboard**: Automatically compiles visual canvas artboards into clean, production-ready React/TypeScript or HTML/Tailwind components directly in your project.

### 4. Vibe Time-Machine
Never fear an agent breaking your working repository again. The **Vibe Time-Machine** (`src-tauri/src/vibe_time_machine.rs`, `src/vibe-time-machine.ts`) captures turn-by-turn Git-backed snapshots:
- Instant zero-risk rollbacks to any prior conversation turn.
- Turn branching: fork an earlier turn into a new alternate task without losing current project history.
- Visual timeline with before/after diff previewing for every agent action.

### 5. Sketch-Over-Live-Preview & Auto-Heal Loop
- **Live Visual Annotations** (`src/live-sketch.ts`, `src/live-artifacts.ts`): Draw, highlight, circle bugs, and write notes directly atop live web previews and mobile simulators. Annotations are rasterized with coordinate metadata and passed directly to multimodal agent vision models.
- **Auto-Heal Runtime Loop** (`src/auto-heal.ts`): Intercepts uncaught browser runtime exceptions and console errors in live previews, packages concise stack traces, and prompts the coding agent to fix them automatically.

### 6. Push-to-Talk Voice Wave
Hands-free voice prompting with zero perceptible input latency (`src/voice-vibe.ts`). Incorporates a live reactive Web Audio frequency visualizer directly above the composer with instant speech-to-text streaming.

### 7. Universal Harness Compatibility
Run every major coding agent and CLI side-by-side in one window:
- **Claude Code**: Anthropic Claude Opus 5.5 / Claude Fable 5.1 / Claude Sonnet 5.5
- **Codex**: OpenAI GPT 6 Astra / GPT-6.1 Sol / GPT-6 Sol
- **Kimi Code**: Moonshot AI Kimi k3 / Kimi k3.1
- **OpenCode**: ACP Relay protocol
- **GLM Coding Plan**: Zhipu AI GLM-5.3 / GLM-5.3-flash
- **Xiaomi MiMo**: Relayed through Claude Code
- **Antigravity**: Google DeepMind Antigravity CLI & ACP (Gemini 2.0 Flash / Pro & Gemini 3.x Flash)
- **xAI Grok Build**: xAI Grok 4.7 / Grok 4.6
- **Pi**: RPC Mode
- **DeepSeek**: DeepSeek V4.1 flash / V4 through ACP

### 8. Additional Power Features
- **Standalone Chats** (`~/Swarm Chats`): Scratchpad conversations outside of any git repository for rapid debugging, script writing, or general inquiries.
- **Token Saver** (`src/token-saver.ts`): Built-in optimization packs (Caveman Lite/Full/Ultra, Lean code, Quiet tools, RTK) slashing output token overhead by 40%–70%.
- **Local Tart VMs & Cloud Sandboxes**: Hardware-accelerated headless Linux/macOS VMs on Apple silicon (Tart), alongside Daytona, Cloudflare Container Workers, and AWS SSM Sandboxes.
- **Omni-Channel Bots**: Deploy agents into Telegram, Slack, Discord, WhatsApp, or local web chat with native approval hooks and memory retention.
- **Quick Launcher Overlay** (`⌘/Ctrl + Shift + Space`): Summon Swarm anywhere in your OS to trigger tasks, check running agents, or inspect status.

| **Idle Host Process RSS** | < 250 MB | **211.3** | MB | **PASSED** |
| **Idle WebKit Network RSS** | < 100 MB | **65.4** | MB | **PASSED** |
| **Total Idle Settled RAM (Stripped Release)** | < 180 MB | **~120.0** | MB | **EXCELLENT** |
