# PandaCode 0.2.25

- See account usage limits and reset times for supported, configured agents from the new Usage panel beside Settings and Help.
- Thread titles can now follow the conversation as it develops. Titles you set yourself stay unchanged.
- Tool calls appear in compact, expandable groups of up to five, with agent messages kept in order between groups in conversations, board tasks, and the quick overlay.
- Expanded tool details stay open as responses stream, and the generating status follows the current activity.
- Fixed the browser preview going blank when a slash-command menu opens beside it.

Usage availability depends on the installed harness and account. Unsupported providers show an explicit unavailable state.
