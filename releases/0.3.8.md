# A clearer workers panel

## Agent teams

- **The workers panel shows each worker at a glance.** The header reads "Architect is working…" with a task count, and each worker gets its own row: a status icon with its harness logo, the worker's name, and a coloured status (Working.., Needs input, Queued, Done, Failed) followed by its model. Long lists fade out at the bottom.

## Attachments

- **No toast when you paste an image.** The image already shows up in the composer, so the "Image attached from the clipboard" toast is gone. Dropping files still confirms what was attached.

## For contributors

- Release builds are about 30 seconds faster: the Rust library now builds only the output the desktop app links.
- `npm run package:fast` builds an app with the new `fast-release` profile (no LTO, parallel codegen), about twice as fast clean and much faster after an edit. Shipped builds still use the release profile.
- CI caches Rust builds and no longer runs `cargo check` before Clippy.
- The browser suite runs 4 workers by default (`PW_WORKERS` overrides), about 3.5 minutes instead of 8.

## Known limitations

- Eight browser tests fail before and after this release (in `ui.spec.ts`, `jev-assist.spec.ts` and `jev-live.spec.ts`); they are unrelated to these changes and still need fixing.
