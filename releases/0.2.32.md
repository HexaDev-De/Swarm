# PandaCode 0.2.32

- Run projects directly from the workspace header or a changed-files summary. Agents can maintain a `pandacode-run.sh` launch script and open the resulting local preview in PandaCode's browser. Runs use a terminal tab belonging to the task.
- Changed-files summaries capture edits attributed to that task and its workers, instead of including unrelated changes from the entire checkout. Saved diffs remain available after the files change again.
- Resize the right sidebar by dragging its edge. The saved width adapts to the available space, including when the left sidebar is collapsed.
- Imported terminal settings keep fonts, colors, and cursor preferences without importing oversized font sizes.
- Worker scheduling respects the team's parallel limit, starts independent assignments together, and explains when work is queued behind a conflicting file assignment or dependency. Read-only assignments can run alongside other work.
- Existing Codex architect sessions refresh their app-tool catalog while preserving conversation context, so new team tools are available after an update.
- The Codex usage panel includes a keyboard-accessible daily activity calendar with per-day token counts.
- Run Script preview paths now use consistent validation on Windows, macOS, and Linux, with native Windows Bash discovery covered by platform-aware checks.

This is an Alpha preview. macOS uses ad-hoc signing without Apple notarization;
Windows does not yet have Authenticode signing. All platform updates retain
cryptographic signature verification. Linux requires X11/XWayland. Run scripts
on Windows require a native Bash installation such as Git Bash.
