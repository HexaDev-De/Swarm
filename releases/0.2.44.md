# PandaCode 0.2.44

- **Virtual machines for agents (Apple silicon Macs).** A new VM tab in the right sidebar runs Linux (Ubuntu, Debian, Fedora) and macOS (Tahoe, Sequoia) virtual machines on Apple's Virtualization framework.
  - Agents can use them like a person, seeing the screen, clicking, dragging, scrolling, typing and pressing shortcuts, and can run shell commands inside them for isolated work: installing packages, building and running code, starting servers.
  - You can use the same screen yourself: click, scroll and type into it from the panel.
  - "Set up VMs" downloads Tart from Cirrus Labs and checks Apple's notarization and the developer signature before installing it. Tart is free for personal and small-team use.
  - Built to save memory: VMs run without a window, Linux VMs start with 2 GB, copies share disk space with their image, and a VM nobody has used for 10 minutes is suspended (macOS) or stopped (Linux). VMs started by PandaCode are released when it quits.
  - Console-only Linux VMs can get a light Xfce desktop with one click, so agents can use them with computer use.
  - Share the current project with a VM read-only when it starts; the agent copies what it needs inside the VM.

Known limitations: downloads are large (Linux about 5 GB, macOS about 30 GB). Windows VMs and cloud sandboxes (Daytona, AWS, Cloudflare) and deployments are coming in the next releases. A VM started outside PandaCode must be stopped and started here before its screen can be shown.

This is an Alpha preview. macOS uses ad-hoc signing without Apple notarization;
Windows does not yet have Authenticode signing. All platform updates retain
cryptographic signature verification. Linux requires X11/XWayland.
