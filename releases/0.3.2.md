# GitHub works when opened from Finder

- **Fixes the GitHub view and other GitHub features saying the GitHub CLI isn't connected** when PandaCode was opened from Finder or the Dock, even though `gh` was installed and signed in. PandaCode now finds `gh` where your terminal does (Homebrew, `/usr/local/bin`, `~/.local/bin` and more).
- **Clearer connect screen.** If GitHub can't be reached, the GitHub view shows the GitHub CLI's own message and what to do about it.
