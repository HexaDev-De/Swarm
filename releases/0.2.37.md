# PandaCode 0.2.37

- **Clearer, more modern windows.** Settings, Agent usage, Bots, Import conversations, Go to anything and every other modal now use a lighter, more transparent glass. The workspace stays visible behind them, edges are fine hairlines with rounder corners and softer shadows, and the muddy tint is gone.
- Fields, dropdowns, setting groups and buttons inside modals are frosted to match, with a soft yellow focus ring. The close button is now a small round control.
- Go to anything and Import conversations each have a single clean search field.

With Reduce transparency or Increase contrast turned on, modals keep solid backgrounds.

This is an Alpha preview. macOS uses ad-hoc signing without Apple notarization;
Windows does not yet have Authenticode signing. All platform updates retain
cryptographic signature verification. Linux requires X11/XWayland.
