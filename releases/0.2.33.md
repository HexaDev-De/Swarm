# PandaCode 0.2.33

- Agent usage now opens on an Overview. It shows the estimated API cost for the past week, month, or year, and the average of each agent's most-used limit window.
- The Overview lists every agent with its color, limit meter, cost share, tokens and sessions. It also has a daily cost chart, token totals with cache savings, and a breakdown by model or by day.
- Each agent has its own tab with its limit windows, its cost and models for the period, and a year activity calendar.
- Estimated API cost is read from Claude Code and Codex session logs on this computer, only while Agent usage is open. Only token counts are kept and nothing is uploaded. Reopening reads only new log data.
- Prices come from LiteLLM's public price list, refreshed at most daily, with a bundled copy for offline use. They include cache reads, cache writes and long-context rates.

Known limitations:
- The estimate shows what the same tokens would cost through the API, not what a subscription charges. Batch, priority and fast-mode pricing are excluded.
- Models missing from the price list are shown as unpriced.
- Cost is not tracked for Kimi, OpenCode, GLM, Grok, Antigravity or MiMo. Their calendars count prompts sent from PandaCode.
- The first scan of large Codex histories can take several seconds.

This is an Alpha preview. macOS uses ad-hoc signing without Apple notarization;
Windows does not yet have Authenticode signing. All platform updates retain
cryptographic signature verification. Linux requires X11/XWayland.
